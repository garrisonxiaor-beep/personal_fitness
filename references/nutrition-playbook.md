# Nutrition Playbook

## Foundation First
Start with protein adequacy, calorie alignment, fiber, fruit and vegetables, and meal consistency.

## Carb Cycling Position
Use carb cycling only for users with enough training consistency and adherence to benefit from extra structure.

## Anti-Inflammatory Position
Use anti-inflammatory eating as a quality-of-food framework rather than a cure claim.

## Adherence Rule
If the user struggles with execution, simplify meals before increasing precision.
