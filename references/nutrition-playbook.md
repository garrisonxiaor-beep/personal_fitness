# Nutrition Playbook

Quick-reference rules for nutrition decisions. For detailed strategies, read `references/nutrition-advanced.md`.

## Foundation First

Before any advanced strategy, confirm these basics:

1. **Protein floor hit**: at least 1.6 g/kg/day
2. **Calories aligned with goal**: deficit for fat loss, surplus for hypertrophy, maintenance for recomposition
3. **Vegetables and fiber**: 2+ servings of vegetables, 25-35 g fiber
4. **Meal consistency**: regular meal structure, not chaotic eating
5. **Reduced ultra-processed food**: whole foods as the default

## Decision Flow

```
User asks about nutrition
  → Is there a training or body-composition decision? (No → don't use this skill)
  → Is protein adequate? (No → fix protein first)
  → Are calories aligned with goal? (No → adjust calories)
  → Is adherence sustainable? (No → simplify before optimizing)
  → Does the user qualify for advanced strategies? (Check eligibility)
  → Apply the smallest useful nutrition change
```

## Carb Cycling Quick Reference

### Eligibility (all must be true)
- 4+ weeks consistent training + nutrition tracking
- Medium-to-high adherence demonstrated
- Clear reason to benefit (plateau, hard training fuel needs)

### Default schedule
| Day | Carbs | When |
|---|---|---|
| High | 5-7 g/kg | Heavy training day (legs, SBD) |
| Moderate | 3-4 g/kg | Moderate training day |
| Low | 1.5-2.5 g/kg | Rest day or light training |

### Coach-style defaults
- 凯圣王×谭指导 → structured, mapped to SBD schedule
- Pamela Reif → high/low based on training vs rest
- 周六野 / 韩小四 → skip carb cycling, use portion control
- 海洋饼干 → moderate structure, eating-out-friendly

## Plateau Quick Check

| Symptom | Check first | Action |
|---|---|---|
| Weight stall 2-3 weeks | Adherence + weekly average | Add steps before cutting food |
| Hunger very high | Protein + fiber intake | Raise protein and fiber before accepting more hunger |
| Performance crashing | Calories + sleep + stress | Increase calories 100-200 kcal or take diet break |
| Waist not changing | Photos + measurement consistency | Verify measurement method; check sodium cycle |

## Eating-Out Defaults

| Situation | Default plate |
|---|---|
| Chinese restaurant | 蛋白质菜+蔬菜+半份米饭 |
| Fast food | Grilled chicken sandwich or protein bowl; skip fries |
| Hotpot | Lean meat + lots of vegetables; less dipping sauce |
| Buffet | Protein first → vegetables → moderate starch → skip dessert |
| Coffee shop | Americano + protein snack; skip sugary pastries |

## Adherence Rule

**Simplify before increasing precision.**

If the user cannot sustain:
- Detailed macro tracking → switch to portion control
- Portion control → switch to meal defaults
- Meal defaults → switch to "protein first, eat less overall"

Do not add complexity to a plan the user is already failing to follow.
