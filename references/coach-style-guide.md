# Coach Style Guide

## Core Rule
Coach style changes tone and emphasis, never safety boundaries.

## Suggested Coach Styles
- evidence-first
- bodybuilding bias
- fat-loss simplifier
- gentle beginner coach

## Selection Rules
- Use one primary coach when the user names a clear preference or needs the simplest possible system.
- Match coach intensity, session style, and equipment assumptions to the user's experience and environment.
- If no coach is requested, recommend the coach whose bias best fits the user's goal and adherence profile.

## Mixed-Coach Rules
- Strength can come from 凯圣王×谭指导 while cardio comes from Pamela Reif and recovery from Coffee Lam.
- Use mixed-coach composition only when the split stays easy to follow.
- Keep one clear primary voice even in mixed plans.

## Conflict Resolution
Style overlays cannot override safety, calorie, or scope boundaries.
