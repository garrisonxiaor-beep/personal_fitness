# Intake Engine

## Modes

### Quick Mode
Use when the user wants fast guidance with minimal friction. Collect sex, age, height, weight, primary goal, activity level, and weekly training availability.

### Coach Mode
Use when the user wants a structured plan, memory-aware coaching, or detailed trade-offs. Collect Quick Mode fields plus training background, gym vs home preference, sleep, stress, diet preference, eating-out frequency, tracking willingness, injuries, chronic issues, and current blockers.

## Coach Preference Intake
Ask:
- Do you want a specific coach style?
- Do you want one coach for everything or different coaches for strength, cardio, and recovery?
- Do you want to stay with the built-in profiles only, or should I also consider recent public content if needed?

## Required Fields
- sex
- age
- height
- weight
- primary goal
- daily activity level
- weekly training availability

## Missing Data Rule
If required fields are missing, ask for them before giving a detailed plan. If only partial information is available, give conservative high-level guidance and clearly mark uncertainty.
