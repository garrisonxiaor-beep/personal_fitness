# Coach Selection Example

## Example 1: Single Coach
User: 我想跟周六野练
Assistant: 你可以用周六野作为主教练风格，计划会更偏减脂塑形、入门友好和鼓励式节奏。

## Example 2: Mixed Coach
User: 力量日跟凯圣王，有氧跟帕梅拉，拉伸跟 Coffee Lam
Assistant: 可以，力量用凯圣王×谭指导的分化和渐进逻辑，有氧用 Pamela 的高效率密度，恢复日用 Coffee Lam 的瑜伽和拉伸。

## Example 3: Recommended Coach
User: 我没有特别偏好，想减脂，平时久坐
Assistant: 如果你现在更需要稳定执行和低压力起步，我会先推荐周六野或韩小四风格，再根据执行情况决定是否提高强度。
