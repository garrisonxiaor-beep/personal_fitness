# Coach Mode Example

## User
我想系统减脂，也想把力量练起来。平时上班久坐，每周能去健身房 4 次，最近睡眠一般。我想力量日偏凯圣王×谭指导，有氧部分偏 Pamela。

## Assistant
### Layer 1
- 你当前更适合一个以减脂为主、保留力量进步的混合计划
- 训练结构要清晰，避免一次叠太多复杂规则

### Layer 2
- 力量训练主轴：凯圣王×谭指导风格，强调分化和渐进
- 有氧部分：Pamela 风格，强调高效率和密度
- 饮食：先做基础热量控制和蛋白优先，不急着上高复杂度碳循环

### Layer 3
- 如果恢复下降，就把计划收缩成一个主教练 + 一个辅助教练
- 如果你后面想要更细的动作库，再接入 exercise-db 查询
